# QuickBox Releases

这是 QuickBox 的公开更新渠道，只存放正式版安装包、`latest.yml`、blockmap 和校验文件，不包含应用源码。

- 最新版本与下载：https://github.com/rispika/quickbox-releases/releases/latest
- 客户端通过 `electron-updater` 读取本仓库的 `releases.atom`、`releases/latest` 和 `latest.yml`
- 源码仓库保持私有；发布由私有仓库的 Release 工作流写入这里

请只从本仓库的 Releases 下载安装包。当前 Windows 安装包未签名，系统可能提示“未知发布者”，安装前请核对发布页中的 SHA-256。
